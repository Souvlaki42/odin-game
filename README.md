# Odin game

A small point and click farming game written in Odin

## "Dependencies"

Uses [raylib](https://github.com/odin-lang/Odin/tree/master/vendor/raylib).
Everything is vendored though so you don't need to install anything.

## Run

Literally download [Odin](https://odin-lang.org/docs/install/), clone this repo and run `odin run .`.
